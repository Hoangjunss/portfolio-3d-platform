## Lỗi trong plan 18b

### M1 (MAJOR) — tiền đề sai: `app/admin/` được khẳng định là chưa tồn tại

Plan nói ở ba chỗ rằng plan 13/14 chưa chạy và `app/admin/` chưa có trên đĩa. Thực tế:

    frontend/app/admin/login/page.tsx
    frontend/app/admin/(dashboard)/layout.tsx
    frontend/app/admin/(dashboard)/page.tsx
    frontend/app/admin/(dashboard)/leads/page.tsx
    frontend/app/admin/(dashboard)/templates/page.tsx

Hệ quả nặng nhất nằm ở **Step 1**, vì nó là bước đầu tiên: "Expected: `app/` contains `globals.css`,
`layout.tsx`, `page.tsx` only — no `admin/` directory yet." Bước kiểm đầu tiên của plan **sai so với
thực tế**, nên lượt giao mở plan ra là gặp ngay mâu thuẫn.

Đây đúng chữ ký của hai lượt 0/N đã ghi trong STATUS.md (plan 15 lần 1, plan 17 lần 1): cả hai đều
bắt đầu bằng một bước kiểm và chết trước khi viết file nào.

**Điều quan trọng:** kết luận kỹ thuật của plan **vẫn đúng** sau khi sửa tiền đề. `admin/` đã nằm
sẵn ngoài `(public)` — đó chính là đích cần tới. Chỉ cây public phải di chuyển. Không phải viết lại
plan, chỉ sửa lời mô tả hiện trạng.

### M2 (MINOR nhưng dễ lọt) — Step 4 sẽ khiến `lang` bị đổi lặng lẽ

Step 4 bảo "confirm root layout khớp shape dưới đây", và shape đó viết `<html lang="vi">`. File thật
là `lang="en"`. Một bước "confirm" mà mẫu đối chiếu khác thực tế sẽ đẩy lượt giao tới chỗ *sửa* file
cho khớp mẫu — một thay đổi hành vi không ai yêu cầu, và không test nào bắt được.

Cùng loại với lỗi đã ghi ở plan 07 lần 2 (thêm `@WithMockUser` thừa vào test cũ — phải `git diff`
cả file mới thấy).

Đã sửa mẫu về `lang="en"` và ghi rõ đây là bước chỉ đọc.

### M3 (MAJOR) — Step 5 không chạy được như viết

Bản gốc: `npm run build && npm run dev &` rồi `curl` ngay.

Ba vấn đề: `curl` chạy đua với lúc server khởi động nên gần như chắc chắn nhận connection refused
và báo hỏng giả; không có `kill` nên server sống quá bước, giữ cổng 3000 cho mọi lần chạy sau; và
`npm run dev` không kiểm được cái đang cần kiểm — route manifest là sản phẩm của `build`, nên phải
`npm start` trên chính bản build vừa tạo.

Đã thay bằng `npm run build` → `npm start &` → vòng chờ readiness 30s → `curl` → `kill`.

## Lỗi trong plan 19

### M4 (MAJOR) — file tự mâu thuẫn về chỗ mount

Task 4 (dòng 256, 259) đã được sửa để nhắm `app/(public)/layout.tsx`. Nhưng ba chỗ khác trong **cùng
file** vẫn giữ bản cũ:

- Architecture: "Both render inside `app/layout.tsx`"
- Task 2 Interfaces: "Produces: `<SiteNav />`, mounted once in `app/layout.tsx`"
- Task 3 Interfaces: "Produces: `<SiteFooter />`, mounted once in `app/layout.tsx`"

Lượt giao đọc Task 2/Task 3 trước Task 4. Mount vào root layout **chính là** sự cố rò nav/footer
sang `/admin/**` mà plan 18b sinh ra để chặn. Sửa một nửa file còn nguy hơn không sửa.

sai rằng `app/admin/` là thư mục thường chưa có route group. 18b đã xử lý xong việc này. Đã viết lại.
