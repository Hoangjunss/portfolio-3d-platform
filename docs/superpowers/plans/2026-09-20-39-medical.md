# Medical Demo Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `medical` demo template site (`templates/medical/`) — one of the 29 site plans
under the interactive-demo templates program. Run a real per-site Hallmark design pass, scaffold the
static Next.js export composing `Hero` → `ItemGrid`(treatments) → `PeopleGrid`(doctors) →
`InquiryForm`(appointment request) → `Footer` from `@portfolio/template-kit`, and build its
"Appointment request → Your appointments" interactive feature on `useLocalCollection`.

**Architecture:** This plan is plan 39 in the interactive-demo spec's §9 execution order — one of
plans 31-59, each independent once plan 30 lands. It has one hard prerequisite:
`2026-09-20-30-template-kit-scaffold.md` must be complete and committed (`@portfolio/template-kit`
built, tested, exporting `Hero`, `ItemGrid`, `PeopleGrid`, `Footer`, `InquiryForm`,
`useLocalCollection`, `TemplateTheme`/`assertValidTheme` from its barrel `src/index.ts`). This plan
does not modify `template-kit` itself — it only consumes it. Task 1 runs a real Hallmark design
session (not a scaffold/placeholder step) and commits its own theme output; Task 2 scaffolds the
Next.js app and static composition; Task 3 builds the appointment-request interactive feature and
its interaction test, plus the design-scoring self-audit.

**Tech Stack:** Next.js 15 / React 19 static export (`output: 'export'`), TypeScript, Vitest +
Testing Library + jsdom for the interaction test, `@portfolio/template-kit` as a local workspace
dependency. No backend change — this plan touches nothing under `backend/`.

**Spec:** `docs/superpowers/specs/2026-09-20-site-medical-design.md` (section composition, seed
data shape/content, interactive-feature data flow, Hallmark design brief) plus the two specs it is
scoped by: `docs/superpowers/specs/2026-09-20-interactive-demo-templates-design.md` (§3.1
`useLocalCollection` contract, §3.2 row #9 the appointment-request feature, §5 per-site Hallmark
requirement, §7 the build+interaction test gate, §8 the 10-criterion design scoring gate, §9
execution order) and `docs/superpowers/specs/2026-09-20-template-design-system-design.md` (§3
taxonomy row #9, §4 component behavior/prop contracts, §6 folder/thumbnail/slug convention).

**(e) `AppointmentSection` is a client component (`'use client'`)** mounted inside the otherwise

`docs/superpowers/specs/2026-09-20-site-medical-design.md` §4.4's documented rationale

**(g) `Appointment`'s shape is exactly `{id, name, phone, preferredDoctor, preferredDate}`** per
this plan's own goal statement and spec §4.1 — `email` and `message` are collected by `InquiryForm`
(its base fields are fixed by the kit) but intentionally not carried into the persisted record.

```tsx
'use client';
import { useLocalCollection, InquiryForm } from '@portfolio/template-kit';
import { APPOINTMENT_FIELDS } from '../data/seed';

interface Appointment {
  id: string;
  name: string;
  phone: string;
  preferredDoctor: string;
  preferredDate: string;
}

const APPOINTMENTS_SEED: Appointment[] = [];

export function AppointmentSection() {
  const { items, add, reset } = useLocalCollection<Appointment>(
    'medical-appointments',
    APPOINTMENTS_SEED,
  );

  async function handleSubmit(values: Record<string, string>) {
    add({
      id: crypto.randomUUID(),
      name: values.name,
      phone: values.phone,
      preferredDoctor: values.preferredDoctor,
      preferredDate: values.preferredDate,
    });
  }

  const sorted = [...items].sort((a, b) => b.preferredDate.localeCompare(a.preferredDate));

  return (
    <section className="medical-appointment">
      <h2>Book an appointment</h2>
      <InquiryForm fields={APPOINTMENT_FIELDS} submitLabel="Request appointment" onSubmit={handleSubmit} />
      <aside aria-label="Your appointments">
        <h3>Your appointments</h3>
        {sorted.length === 0 ? (
          <p>No appointments yet — submit the form above and it will appear here.</p>
        ) : (
          <ol>
            {sorted.map((appointment) => (
              <li key={appointment.id}>
                <strong>{appointment.name}</strong>
                <span>{appointment.preferredDoctor || 'Any doctor'}</span>
                <time>{appointment.preferredDate}</time>
              </li>
            ))}
          </ol>
        )}
        <button type="button" onClick={reset}>Reset demo data</button>
      </aside>
    </section>
  );
}
```
