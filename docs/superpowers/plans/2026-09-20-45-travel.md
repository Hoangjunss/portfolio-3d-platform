# Travel / Resort Demo Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `travel` demo template site (`templates/travel/`) — site #15 of 29 under the
interactive-demo templates program. Run a real per-site Hallmark design pass, scaffold the static
Next.js export composing `Hero` → `PricedItemGrid`(rooms/packages) → `ItemGrid`(amenities, with a
static map placeholder) → `InquiryForm`(booking inquiry) → `Footer` from `@portfolio/template-kit`,
and build its "Add to trip" trip-planner interactive feature on `useLocalCollection` +
`SavedItemsPanel`.

**Architecture:** This plan is plan 45 in the interactive-demo spec's §9 execution order — one of
plans 31-59, each independent once plan 30 lands. It has one hard prerequisite:
`2026-09-20-30-template-kit-scaffold.md` must be complete and committed (`@portfolio/template-kit`
built, tested, exporting `Hero`, `PricedItemGrid`, `ItemGrid`, `InquiryForm`, `Footer`,
`SavedItemsPanel`, `useLocalCollection`, `TemplateTheme`/`assertValidTheme` from its barrel
`src/index.ts`). This plan does not modify `template-kit` itself — it only consumes it. Task 1 runs
a real Hallmark design session (not a scaffold/placeholder step) and commits its own theme output;
Task 2 scaffolds the Next.js app and static composition; Task 3 builds the "Add to trip" interactive
feature and its interaction test, plus the design-scoring self-audit.

**Tech Stack:** Next.js 15 / React 19 static export (`output: 'export'`), TypeScript, Vitest +
Testing Library + jsdom for the interaction test, `@portfolio/template-kit` as a local workspace
dependency. No backend change — this plan touches nothing under `backend/`.

**Spec:** `docs/superpowers/specs/2026-09-20-site-travel-design.md` (section composition, seed data
shape/content, trip-planner interactive-feature data flow, booking-inquiry form fields, Hallmark
design brief) plus the two specs it is scoped by:
`docs/superpowers/specs/2026-09-20-interactive-demo-templates-design.md` (§3.1 `useLocalCollection`
contract, §3.2 row #15 the "Add to trip" feature, §3.3 `SavedItemsPanel` contract, §5 per-site
Hallmark requirement, §7 the build+interaction test gate, §8 the 10-criterion design scoring gate,
§9 execution order) and `docs/superpowers/specs/2026-09-20-template-design-system-design.md` (§3

### Design decisions

**(e) `TripPlannerSection` is a client component (`'use client'`)** mounted inside the otherwise
static-exported `page.tsx`, per the Global Constraints render-pattern rule — it receives the static
`ROOMS` array as a prop (not read from `useLocalCollection`, so the rooms/packages grid content
itself matches build-time static HTML with no hydration mismatch) and owns the
`useLocalCollection('travel-my-trip', [])` call driving the "My trip" panel and subtotal; the rest
of the page (`ItemGrid`, the map placeholder, `InquiryForm`, `Footer`) stays server/static-rendered.

**(f) "Add to trip" is idempotent per room/package `id`, not a quantity increment** — per spec §4.3
step 2, clicking "Add to trip" on a room/package already in the trip does nothing (no duplicate
`TripItem`, no qty field on `TripItem` at all), a deliberate, documented divergence from
`CartDrawer`'s qty-based model appropriate to a trip-planner's one-slot-per-room-type semantics.

**(g) The subtotal is derived at render time, never stored as its own `useLocalCollection` field** —
`items.reduce((sum, item) => sum + item.price, 0)`, recomputed on every add/remove so it can never
drift from the persisted `TripItem[]` list, per spec §4.3 step 4.

```tsx
'use client';
import { useLocalCollection, PricedItemGrid, SavedItemsPanel } from '@portfolio/template-kit';
import type { RoomPackage } from '../data/seed';

interface TripItem {
  id: string;
  title: string;
  price: number;
  addedAt: string;
}

const MY_TRIP_SEED: TripItem[] = [];

function formatVnd(amount: number) {
  return new Intl.NumberFormat('vi-VN', { style: 'currency', currency: 'VND' }).format(amount);
}

export function TripPlannerSection({ rooms }: { rooms: RoomPackage[] }) {
  const { items, add, remove, reset } = useLocalCollection<TripItem>('travel-my-trip', MY_TRIP_SEED);

  function handleAddToTrip(room: RoomPackage) {
    if (items.some((item) => item.id === room.id)) return;
    add({ id: room.id, title: room.title, price: room.price, addedAt: new Date().toISOString() });
  }

  const subtotal = items.reduce((sum, item) => sum + item.price, 0);

  return (
    <section className="travel-trip-planner">
      <PricedItemGrid items={rooms} currency="VND" ctaLabel="Add to trip" onSelect={handleAddToTrip} />
      <aside aria-label="My trip">
        <h3>My trip</h3>
        <SavedItemsPanel
          items={items}
          emptyLabel="Your trip is empty — add a room or package above"
          onRemove={remove}
          renderItem={(item: TripItem) => `${item.title} — ${formatVnd(item.price)}`}
        />
        <p className="travel-trip-subtotal">Subtotal: {formatVnd(subtotal)}</p>
        <button type="button" onClick={reset}>Reset demo data</button>
      </aside>
    </section>
  );
}
```
