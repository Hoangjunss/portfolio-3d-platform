# Automotive Demo Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `automotive` demo template site (`templates/automotive/`) — site #19 of 29
under the interactive-demo templates program. Run a real per-site Hallmark design pass, scaffold
the static Next.js export composing `Hero` → `ItemGrid`(vehicle inventory, client-side filterable)
→ `InquiryForm`(financing inquiry) → `Footer` from `@portfolio/template-kit`, and build its "Add to
compare" interactive feature on `useLocalCollection` + `CompareTray`, capped at 3 vehicles.

**Architecture:** This plan is plan 49 in the interactive-demo spec's §9 execution order — one of
plans 31-59, independent of every other site plan once plan 30 lands. It has one hard prerequisite:
`2026-09-20-30-template-kit-scaffold.md` must be complete and committed (`@portfolio/template-kit`
built, tested, exporting `Hero`, `ItemGrid`, `InquiryForm`, `Footer`, `CompareTray`,
`useLocalCollection`, `TemplateTheme`/`assertValidTheme` from its barrel `src/index.ts`). This plan
does not modify `template-kit` itself — it only consumes it, including `ItemGrid`'s existing
`{ items, columns? }` contract with no filter prop and no per-item action slot (see Task 2's design
decision on how filtering and the compare action are composed around, not into, `ItemGrid`). Task 1
runs a real Hallmark design session and commits its own theme output; Task 2 scaffolds the Next.js
app and static+filterable composition; Task 3 builds the compare-tray interactive feature, its
interaction test, and the design-scoring self-audit.

**Tech Stack:** Next.js 15 / React 19 static export (`output: 'export'`), TypeScript, Vitest +
Testing Library + jsdom for the interaction tests, `@portfolio/template-kit` as a local workspace
dependency. No backend change — this plan touches nothing under `backend/`.

**Spec:** `docs/superpowers/specs/2026-09-20-site-automotive-design.md` (section composition, seed
data shape/content, filter behavior, compare data flow + 3-item cap UX, Hallmark design brief) plus
the two specs it is scoped by: `docs/superpowers/specs/2026-09-20-interactive-demo-templates-design.md`
(§3.1 `useLocalCollection` contract, §3.2 row #19 the compare feature, §3.3 `CompareTray`
contract, §5 per-site Hallmark requirement, §7 the build+interaction test gate, §8 the
10-criterion design scoring gate, §9 execution order) and
`docs/superpowers/specs/2026-09-20-template-design-system-design.md` (§3 taxonomy row #19, §4
component behavior/prop contracts, §6 folder/thumbnail/slug convention).

### Design decisions

**(e) `InventorySection` grows to own both halves — filtering (Task 2) and the compare tray (this
task) — in one client component, not two.** Both are page-level, non-kit concerns operating on the
same filtered vehicle list (the "Add to compare" button rendered per vehicle needs to know which
vehicles are currently visible after filtering); splitting them into separate components would
require lifting `filteredVehicles` back up into `page.tsx` for no benefit, so this task extends the
existing file rather than introducing a second client component.

**(f) 3-item cap UX: disable, never silently drop or replace.** Per spec §4.3: once the compare tray
holds 3 items, every "Add to compare" button for a vehicle NOT already in the tray is disabled and
relabelled "Compare full (3/3)"; a single inline message near `CompareTray` explains why. The
full/not-full state is derived live from `items.length` on every render (not a separate `useState`
flag) so it self-corrects the instant a `remove` drops the count below 3 — no manual re-sync needed.

// templates/automotive/app/InventorySection.compare.test.tsx
import { describe, it, expect, beforeEach } from 'vitest';
import { render, screen, fireEvent, waitFor } from '@testing-library/react';
import { InventorySection } from './InventorySection';

function addToCompare(vehicleLabel: RegExp) {
  fireEvent.click(screen.getByRole('button', { name: new RegExp(`add.*compare.*${vehicleLabel.source}`, 'i') }));
}

beforeEach(() => {
  window.localStorage.clear();
});

describe('InventorySection compare tray', () => {
  it('shows an empty compare tray before any vehicle is added', () => {
    render(<InventorySection />);
    expect(screen.getByText(/compare is empty|nothing to compare/i)).toBeInTheDocument();
  });

  it('adding up to 3 vehicles shows all 3 in the CompareTray', async () => {
    render(<InventorySection />);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[0]);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[1]);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[2]);

    await waitFor(() => {
      expect(screen.getByText(/Hakura Cursa/i)).toBeInTheDocument();
      expect(screen.getByText(/Hakura Solara/i)).toBeInTheDocument();
      expect(screen.getByText(/Vantor Ridge/i)).toBeInTheDocument();
    });
  });

  it('persists the 3 compared vehicles across remount (simulated reload)', async () => {
    const { unmount } = render(<InventorySection />);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[0]);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[1]);
    await waitFor(() => expect(screen.getByText(/Hakura Solara/i)).toBeInTheDocument());
    unmount();

    render(<InventorySection />);
    await waitFor(() => {
      expect(screen.getByText(/Hakura Cursa/i)).toBeInTheDocument();
      expect(screen.getByText(/Hakura Solara/i)).toBeInTheDocument();
    });
  });

  it('disables adding a 4th vehicle once the tray holds 3, with an explanatory message', async () => {
    render(<InventorySection />);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[0]);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[1]);
    fireEvent.click(screen.getAllByRole('button', { name: /add to compare/i })[2]);
    await waitFor(() => expect(screen.getAllByRole('button', { name: /compare full/i }).length).toBeGreaterThan(0));

    expect(screen.getByText(/compare is full/i)).toBeInTheDocument();

  id: string;
  title: string;
  price: number;
  specs: Vehicle['specs'];
}

const COMPARE_SEED: CompareEntry[] = [];
const COMPARE_CAP = 3;

type TypeFilter = 'all' | Vehicle['type'];
type PriceRangeFilter = 'all' | 'under-700m' | '700m-1b' | 'over-1b';

function inPriceRange(price: number, range: PriceRangeFilter): boolean {
  if (range === 'all') return true;
  if (range === 'under-700m') return price < 700_000_000;
  if (range === '700m-1b') return price >= 700_000_000 && price <= 1_000_000_000;
  return price > 1_000_000_000;
}

export function InventorySection() {
  const [typeFilter, setTypeFilter] = useState<TypeFilter>('all');
  const [priceRangeFilter, setPriceRangeFilter] = useState<PriceRangeFilter>('all');
  const { items: compared, add, remove, reset } = useLocalCollection<CompareEntry>(
    'automotive-compare',
    COMPARE_SEED,
  );

  const filteredVehicles = VEHICLES.filter(
    (v) => (typeFilter === 'all' || v.type === typeFilter) && inPriceRange(v.price, priceRangeFilter),
  );

  const isFull = compared.length >= COMPARE_CAP;
  const comparedIds = new Set(compared.map((c) => c.id));

  function handleAdd(vehicle: Vehicle) {
    if (comparedIds.has(vehicle.id) || isFull) return;
    add({
      id: vehicle.id,
      title: `${vehicle.make} ${vehicle.model}`,
      price: vehicle.price,
      specs: vehicle.specs,
    });
  }

  return (
    <section className="automotive-inventory">
      <div role="group" aria-label="Vehicle type">
        {(['all', 'sedan', 'suv', 'pickup', 'hatchback'] as TypeFilter[]).map((type) => (
          <button key={type} type="button" onClick={() => setTypeFilter(type)} aria-pressed={typeFilter === type}>
            {type}
          </button>
        ))}
      </div>
      <label>
        Price range
        <select value={priceRangeFilter} onChange={(e) => setPriceRangeFilter(e.target.value as PriceRangeFilter)}>
          <option value="all">All prices</option>
          <option value="under-700m">Under 700M VND</option>
          <option value="700m-1b">700M - 1B VND</option>
          <option value="over-1b">Over 1B VND</option>
        </select>
      </label>

      {filteredVehicles.length === 0 ? (
        <p>No vehicles match these filters.</p>
      ) : (
        <ItemGrid
          items={filteredVehicles.map((v) => ({
            id: v.id,
            title: `${v.make} ${v.model}`,
            description: `${v.year} · ${v.specs.engine} · ${v.specs.seats} seats`,
            image: v.image,
          }))}
          columns={3}
        />
      )}

      <div className="automotive-compare-actions">
        {filteredVehicles.map((vehicle) => {
          const alreadyAdded = comparedIds.has(vehicle.id);
          const disabled = alreadyAdded || isFull;
          return (
            <button
              key={vehicle.id}
              type="button"
              disabled={disabled}
              onClick={() => handleAdd(vehicle)}
            >
              {alreadyAdded ? 'Added' : isFull ? 'Compare full (3/3)' : `Add to compare — ${vehicle.make} ${vehicle.model}`}
            </button>
          );
        })}
      </div>

      {isFull ? <p role="status">Compare is full — remove a vehicle below to add another.</p> : null}

      <aside aria-label="Compare">
        {compared.length === 0 ? (
          <p>Compare is empty — add up to 3 vehicles to compare them side by side.</p>
        ) : (
          <CompareTray
            items={compared}
            onRemove={remove}
            renderItem={(entry: CompareEntry) => (
              <div>
                <strong>{entry.title}</strong>
                <p>{new Intl.NumberFormat('vi-VN', { style: 'currency', currency: 'VND' }).format(entry.price)}</p>
                <ul>
                  <li>{entry.specs.engine}</li>
                  <li>{entry.specs.seats} seats</li>
                  <li>{entry.specs.fuel}</li>
                  <li>{entry.specs.transmission}</li>
                </ul>
              </div>
            )}
          />
        )}
        <button type="button" onClick={reset}>Reset demo data</button>
      </aside>
    </section>
  );
}
