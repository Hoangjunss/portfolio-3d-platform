# Legal Demo Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `legal` demo template site (`templates/legal/`) — the twentieth and last of the
original 20 sites under the interactive-demo templates program (plans 31-50). Run a real per-site
Hallmark design pass, scaffold the static Next.js export composing `Hero` → `ItemGrid`(practice
areas) → `PeopleGrid`(attorneys, `roleLabel="Attorneys"`) → `ItemGrid`(case results, text-focused
reuse) → `InquiryForm`(case inquiry) → `Footer` from `@portfolio/template-kit`, and build its
"Case inquiry → Your inquiries" interactive feature on `useLocalCollection`.

**Architecture:** This plan is plan 50 in the interactive-demo spec's §9 execution order — the last
of plans 31-50 (the original 20 categories' block; plans 51+ are the extra e-commerce/blog/CRM
variants, out of scope here). It has one hard prerequisite:
`2026-09-20-30-template-kit-scaffold.md` must be complete and committed (`@portfolio/template-kit`
built, tested, exporting `Hero`, `ItemGrid`, `PeopleGrid`, `Footer`, `InquiryForm`,
`useLocalCollection`, `TemplateTheme`/`assertValidTheme` from its barrel `src/index.ts`). This plan
does not modify `template-kit` itself — it only consumes it. Task 1 runs a real Hallmark design
session (not a scaffold/placeholder step) and commits its own theme output; Task 2 scaffolds the
Next.js app and static composition; Task 3 builds the case-inquiry interactive feature and its
interaction test, plus the design-scoring self-audit.

**Tech Stack:** Next.js 15 / React 19 static export (`output: 'export'`), TypeScript, Vitest +
Testing Library + jsdom for the interaction test, `@portfolio/template-kit` as a local workspace
dependency. No backend change — this plan touches nothing under `backend/`.

**Spec:** `docs/superpowers/specs/2026-09-20-site-legal-design.md` (section composition, seed data
shape/content, interactive-feature data flow, Hallmark design brief) plus the two specs it is
scoped by: `docs/superpowers/specs/2026-09-20-interactive-demo-templates-design.md` (§3.1
`useLocalCollection` contract, §3.2 row #20 the case-inquiry feature, §5 per-site Hallmark
requirement, §7 the build+interaction test gate, §8 the 10-criterion design scoring gate, §9
execution order) and `docs/superpowers/specs/2026-09-20-template-design-system-design.md` (§3's
taxonomy row 20, §4 component behavior/prop contracts, §6 folder/thumbnail/slug convention).

```tsx
'use client';
import { useLocalCollection, InquiryForm } from '@portfolio/template-kit';

interface CaseInquiry {
  id: string;
  name: string;
  phone: string;
  caseType: string;
  submittedAt: string;
}

const INQUIRY_SEED: CaseInquiry[] = [];

const CASE_TYPE_FIELD = {
  name: 'caseType',
  label: 'Case type',
  type: 'text' as const,
  required: true,
};

export function CaseInquirySection() {
  const { items, add, reset } = useLocalCollection<CaseInquiry>('legal-inquiries', INQUIRY_SEED);

  async function handleSubmit(values: Record<string, string>) {
    add({
      id: crypto.randomUUID(),
      name: values.name,
      phone: values.phone,
      caseType: values.caseType,
      submittedAt: new Date().toISOString(),
    });
  }

  const sorted = [...items].sort((a, b) => b.submittedAt.localeCompare(a.submittedAt));

  return (
    <section className="legal-case-inquiry">
      <h2>Case inquiry</h2>
      <InquiryForm fields={[CASE_TYPE_FIELD]} submitLabel="Submit inquiry" onSubmit={handleSubmit} />
      <aside aria-label="Your inquiries">
        <h3>Your inquiries</h3>
        {sorted.length === 0 ? (
          <p>No inquiries yet — submit the form above and it will appear here.</p>
        ) : (
          <ol>
            {sorted.map((inquiry) => (
              <li key={inquiry.id}>
                <strong>{inquiry.name}</strong>
                <span>{inquiry.caseType}</span>
                <time dateTime={inquiry.submittedAt}>{new Date(inquiry.submittedAt).toLocaleString('vi-VN')}</time>
              </li>
            ))}
          </ol>
        )}
        <button type="button" onClick={reset}>Reset demo data</button>
      </aside>
    </section>
  );
}
```
